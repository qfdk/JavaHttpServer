## Java Serveur
[![Build Status](https://travis-ci.org/qfdk/JavaHttpServer.svg)](https://travis-ci.org/qfdk/JavaHttpServer)
### Introduction

* SocketChannel for client
* ServerSocketChannel for serveur
* Java 简易Http 服务器
* wwwroot文件夹下存放文件
* 需要的可以自己更改代码

### How to use ?

```bash
javac Serveur.java&&java Serveur
```
或者

直接打包运行jar文件，带有GUI界面。
